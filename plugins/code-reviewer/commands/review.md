# Review Command

Use this command when you want a focused code review of local changes, a diff, or a pull request.

## Prompt

Review the current change set for correctness, regressions, security risk, performance risk, and missing tests.

Start with findings ordered by severity. Each finding must include the affected file and line when available, the concrete problem, and the smallest practical fix direction.

If no findings are present, say that directly and list any verification gaps.

## Suggested Invocation

```text
Review my current changes with the code-review skill.
```
