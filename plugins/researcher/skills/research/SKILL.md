# Research

Use an evidence-first research workflow. Do not present unsupported claims as settled facts.

## Research Workflow

1. Define the research question, decision, or claim being investigated.
2. Identify the evidence needed to answer it and note any constraints such as date range, geography, domain, or source type.
3. Gather sources from reliable primary or high-quality secondary references when available.
4. Evaluate each source for authority, recency, relevance, and possible bias.
5. Compare sources when claims conflict, and explain the reason for preferring one source over another.
6. Synthesize the answer with citations attached to the claims they support.
7. Call out uncertainty, missing evidence, stale information risk, and what would change the conclusion.

## Response Format

Use this structure unless the user requests another format:

```markdown
## Answer

Concise synthesis of the best-supported conclusion.

## Evidence

- Source or citation - Specific claim supported by this source.

## Caveats

- Uncertainty, conflict, limitation, or missing source.
```

## Research Standards

- Prefer primary sources, official documentation, papers, standards, datasets, or directly relevant records.
- Use recent sources when the topic changes over time.
- Separate what the sources say from your inference.
- Cite enough context for the user to verify the claim.
- Do not overstate confidence when sources are thin, outdated, or conflicting.
- Ask for permission before using restricted, private, or paid sources that require user credentials.
